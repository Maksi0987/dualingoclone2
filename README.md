=========================================================
ІНФОРМАЦІЯ ПРО ПРОЄКТ LANGUIO (DUALINGO CLONE)
=========================================================

ЗАГАЛЬНА ІНФОРМАЦІЯ
Назва проєкту: Languio (Dualingo Clone)
Автор: Максим Чернищук, група Ф-11
Мета: Створення цілісного веб-сервісу для інтерактивного вивчення іноземних мов із системою гейміфікації (досвід, монети, життя) та розділенням прав доступу.

ТЕХНОЛОГІЧНИЙ СТЕК
- Бекенд: C#, ASP.NET Core MVC (.NET 8)
- База даних: MS SQL Server, Entity Framework Core (Code-First підхід)
- Автентифікація: ASP.NET Core Identity (із підтримкою ролей Admin та User)
- Фронтенд: HTML5, CSS3, JavaScript (Fetch API для асинхронної перевірки)
- UI/UX: Bootstrap 5, кастомні анімації, адаптивний дизайн для мобільних та ПК

РЕАЛІЗОВАНИЙ ФУНКЦІОНАЛ (ЗГІДНО З ТЗ)
1. Авторизація та безпека: Повноцінна реєстрація, вхід, безпечний вихід та заглушка логіки відновлення пароля (безпечний POST-запит).
2. Рольова модель: Чіткий розподіл на звичайного користувача (учня) та адміністратора.
3. Навчальний контент (Admin): Адміністратор має доступ до CRUD-операцій (створення, читання, оновлення, видалення) для курсів, модулів, уроків та окремих питань.
4. Проходження уроків (User): Інтерактивна сторінка уроку. Питання виводяться по черзі. Перевірка відбувається асинхронно (без перезавантаження сторінки). Реалізовано шкалу прогресу та лічильник "життів" (сердечок).
5. Гейміфікація: Після успішного завершення уроку користувачу автоматично нараховується +10 XP (досвіду) та додаткові монети за кожну правильну відповідь.
6. Обробка помилок: Налаштовані коректні стани для порожніх списків, помилок завантаження, браку прав доступу (403/404) та валідація введених даних.
7. Автоматизація розгортання: Проєкт підтримує "чисте клонування" (Clean Clone). При першому запуску автоматично застосовуються міграції (Migrate) та запускається DbSeeder для створення бази.
